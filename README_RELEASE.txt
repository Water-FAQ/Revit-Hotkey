Revit Hotkey v1.0.0

Портативная программа для просмотра и изменения файла горячих клавиш Autodesk Revit.

ЗАПУСК
1. Распакуйте архив в удобную папку.
2. Запустите "Revit Hotkey.exe".
3. Выберите KeyboardShortcuts.xml или нажмите "Загрузить из Revit".

Файл Revit обычно находится здесь:
%APPDATA%\Autodesk\Revit\Autodesk Revit 20XX\KeyboardShortcuts.xml

Перед сохранением рекомендуется закрыть соответствующую версию Revit.
После изменения файла перезапустите Revit.

Установка не требуется. Программа работает локально и не передаёт данные в интернет.
